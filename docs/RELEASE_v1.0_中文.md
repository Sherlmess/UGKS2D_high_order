# v1.0：二维 S2 可复现开发底座

发布日期：2026-09-23。仓库：Sherlmess/UGKS2D_high_order。

## 当前已经实现

1. 宏观 W 与微观 h/b 的二维 WENO5-AO 张量重构，微观共同限制及对应面／体求值。
2. 真实 UGKS 特征线时间积分面通量、面 GQ3 和体 3×3 目标求积、离散宏微矩一致性。
3. 低成本 S2 体碰撞，BGK/Shakhov，保留实际离散 2×2 热流反馈；宏观显式与微观自洽 CN 二阶物理时间推进。
4. O1–O3 等价优化：重构、闭合准备与第一层模板缓存复用；未合入收益不足的 O4/HW1。
5. 原生 Config→InitFlow→Evolution→Residual→更新→Output 流程，以及完整微观保存态复现。
6. S2Steady 定常隐式：宏观 PR2、微观 LU-SGS、守恒修正和同一高阶真实残差；五个不同接受态连续达标的终止逻辑。
7. 完整源码、输入／预期状态、中文阅读／算法／运行指南、来源哈希和最小复现脚本。

## 已验证的结果与边界

- BGK/Shakhov 周期光滑 S2CN2 的可分辨时间阶约1.89–1.98；这是二阶时间证据，不是完整空间五阶认证。
- O1–O3指定状态及轨迹有逐位等价和配对提速证据。
- 周期N8 BGK稳态：I累计1309次与E保存15000步终态W/h/b最大缩放差2.699e-8，通过原1e-6合同，守恒通过。
- 达到同一首次连续五次残差门的有效组合循环成本 I=57.635855s、E=534.818970s，观测比值9.2793。它是单算例跨运行结果，不是普遍加速保证或对全二阶的速度比。
- 整理底座时干净编译及终止逻辑单测通过；六项短程检查共16个接受步，四项终态逐位一致。完整长矩阵未为发布重跑。

当前 S2 入口有硬限制：单rank、均匀[0,2π]²双周期、N8/16/32/64、GH16×16、CK=1、源码常数tau=.1。Pr=1（BGK）或Pr=2/3（Shakhov）有现有用例。定常隐式完整资格只覆盖N8 BGK。

## 后续仍需实现或验证

- 解除周期特例，接入壁面、入口／出口的高阶宏微通量与边界矩相容；优先有界壁面算例，再推进平板边界层。
- 非均匀／拉伸网格及几何映射；相应面体重构和求积不能直接照搬均匀网格。
- 多rank halo、分区公共面守恒和并行正确性／性能；底座原有低阶MPI不等于S2已适配。
- 二维S2可配置变tau与物理黏度律、更多CK与速度求积配置；当前常tau不可仅改配置标签替代。
- 扩展定常隐式到Shakhov、强梯度和壁面工况，评估鲁棒性及实际残差收敛成本。
- 接入非定常隐式／双时间推进，保持原物理时间离散和相位／耗散精度；不能把定常伪时间当成物理时间。
- 计划内二维物理算例、空间／时间／速度分辨率检查、全二阶／Lim式／S2同误差成本对照。
- 平板基本流及扰动／稳定性用途的后续验证。未宣称统一高阶、NS/AP或完整五阶Shakhov碰撞平均。

推进原则：保留宏微观高阶重构＋二阶时间的低成本主线，用目标算例的误差和成本决定是否引入更复杂闭合，不自动恢复昂贵的完整高阶碰撞求解。

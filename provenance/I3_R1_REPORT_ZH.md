# S2D-I3-R1：终止状态机修复与有界隐式收尾

**结论：PASS_STEADY_AGREEMENT_WITH_OBSERVED_SPEEDUP。** 在这个冻结的 N8×8、GH16×16、周期 BGK 问题上，修复后的 S2Steady 从实际保存的累计第 1300 次状态续行，进行了 **9 次真实隐式修正**，在累计第 **1309** 次接受态的真残差评价达到六块原初态尺度绝对 L2 ≤1e-8、连续五个**不同接受态**的门。它与只读复用的显式 E 第 15000 步状态满足同一门，完整 W/h/b 最大缩放差 `2.699e-8`，低于原 `1e-6` 合同。当前算例的首次达标有效轨迹组合循环成本 I 为 `57.635855 s`、E 为 `534.81897 s`，实测比 `9.2793`。这是跨运行、单工况观测；不是物理精确解或统计加速认证。

## 修复范围与身份

执行依据为 [`docs/s2d_i3_r1_termination_closure_execution_2026-09-23.md`](../../docs/s2d_i3_r1_termination_closure_execution_2026-09-23.md)。原冻结 R2 二进制 SHA256 `4a427d8a…b8cef`；本包新 release SHA256 `8d93f9e1…f1c8ef`，完整身份见[参数卡](PARAMETERS.json)及[原生启动记录](runs/I1300_to_gate/launch.json)。[最小源码补丁](SOURCE_PATCH.diff)只涉及 S2Steady 终止、唯一接受态计数、缓存生命周期与终态完整评价；WENO、UGKS 面算子、PR2/LU-SGS、约束、碰撞、物理参数、伪时间和科学门没有修改。旧目录、旧源码与既有 dirty 修改保持原样，未提交或推送。

旧 `S2NativeApplySteadyUpdate` 首次低于门时曾直接返回 `accepted=true`，既无真实修正，也未失效 `evolution_ready`。新分支移除该早退；每个接受态只允许一次计入连续数，单次达标仍按原隐式求解和门接受真实修正。第五个不同接受态达标时，在生成下一提案前正常退出。迭代上限处先为刚接受的状态重建 ghost/斜率及面缓存，再评价真实终态；重复评价不增加连续数。异常修正失败仍保留原提案/回滚路径和最后接受态保存。S2CN2、原低阶路径不改变。这里的 `iter` 是定常伪时间修正编号，不推进物理时间。

## 定向资格与唯一正式续行

独立 Fortran 控制流小测覆盖未达标、四次达标后反弹、第五次达标、重复评价、上限终态待评价、拒绝提案后接受编号不变、编号回退拒绝，结果 `TERMINATION_CONTROL_PASS`。[六个定向单步](qualification/qualification_summary.json)包括 C4 BGK 与 Shakhov 保存态上的旧/新 S2CN2 完整步，以及真实累计第 1300 次状态上的旧/新 S2Steady 单步；每组新旧完整状态逐位一致。隐式单步的初末真残差六块数值也一致，更新日志只因新计数列不同。资格数值墙钟合计 `2.679990 s`。首次 MPI 沙盒端口失败与首次缺失 SDK 的链接失败均属工程问题，见[构建记录](BUILD_NOTES.md)。

正式起点为 I3 `runs/I/checkpoints/checkpoint_0003.bin`，SHA256 `c73a88a3…f9109fe`，与 I3 的 `native_state_final.bin` 完全一致；它**只代表累计 1300 次**。I3 的 1301—1305 次没有可用的完整终态文件，因此本轮从 1300 重算了九次实际修正，不把旧日志的 1305 冒充起点。正式重启的 W/h/b、u/v/weight 与源文件逐位一致；初个真残差按原初态尺度转换后，与 I3 第 1300 次封存评价的六块最大差 `1.65e-24`。`s_restart/s_original` 六块均 ≤1，原生重启门在此例保守；换算表见[原尺度表](analysis/original_scales.csv)。原物理配置、`dt_flux=.005`、`dt_pseudo=.05`、2/1 sweep、回退和 `2e-12` 原生门保持不变；正式上限只设为 200 次修正。

正式运行只有一次启动，返回码 0：9 条接受更新、10 次各对应不同接受态的残差评价（本轮首个第 1300 次评价不并入后续五次窗口），最后五次是累计第 **1305—1309** 次。终态 `ConvergenceStatus.txt` 为 `S2Steady T 9`，原尺度六块最大 L2 `8.62936e-9`，累计连续数 5；终态二进制 SHA256 `90f7ad38…f3`。原生更新的预测差、重启局部守恒漂移、局部矩约束修正后最大分别 `1.67e-15 / 5.55e-16 / 3.10e-24`，低于原 `2e-12` 门。每次原尺度 L2/Linf、唯一态标记及连续计数在[残差原始表](analysis/original_scale_residual.csv)，完整原生日志在 `runs/I1300_to_gate/`。

由原始 W 体积总和复核，I 第 1309 次终态相对最初 Q0 的四分量累计守恒漂移最大 `3.86e-16`；E 第 15000 步为 `4.66e-15`。中间九步按原始 Q0 分母正确换算的逐分量三角上界最大 `1.07e-15`，同样低于 `2e-12`。[守恒表](analysis/cumulative_conservation.csv)与[逐步上界](analysis/conservation_triangle_bounds.csv)保留可复核数字。
